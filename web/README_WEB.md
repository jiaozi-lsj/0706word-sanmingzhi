# Word Dungeon Web 版

这是根据 PRD 和后续修改要求重做的响应式网页版本。

## 打开方式

推荐启动本地网页服务：

```powershell
python -m http.server 5173 -d web
```

然后访问：

```text
http://localhost:5173/
```

老师创建任务页面：

```text
http://localhost:5173/#teacher
```

学生链接由老师页面生成，形如：

```text
http://localhost:5173/?task=task_xxxxxxxx#student
```

也可以直接双击 `web/index.html` 打开。

## 本次修改重点

- 不再生成 exe，改为纯 HTML/CSS/JS 响应式网页。
- 学生端开始页改成游戏入口氛围，不展示词表。
- 学生开始页主标题为：`欢迎XXX，快来用智慧打败这些怪物吧！`
- 游戏支持键盘方向键/WASD，也支持鼠标或触屏按住主角拖动移动。
- 新增男/女勇士选择，主角有待机、行走、冲刺、发射、受伤动作状态。
- 新增三种房间样式：办公废墟、学术图书馆、森林庭院。
- 拾取中文意思必须走到旁边；拿到中文意思后点击英文怪物会发射单词剑/回旋镖，命中后才判定。
- 怪物速度会随房间时间推进，每 3 秒进入更快一档。
- 新增拾取、发射、命中、受伤、通关音效。音效由浏览器实时合成，避免外部素材版权问题。
- 老师端仍可创建任务并生成学生链接。
- 默认进入顺序改为：老师任务创建 → 学生进入/游戏/结算 → 老师结果。
- 已加入 Vercel 部署配置。部署一次即可生成多个任务链接，不需要每次创建任务后重新部署。
- 如果配置了 Vercel KV / Upstash Redis，任务和结果会通过 `/api/task`、`/api/session` 自动保存到云端。
- 如果暂未配置云端存储，老师端会生成“零后端可用链接”，词表会随链接携带，儿童仍可在手机打开复习；但这种模式下老师结果不会自动跨设备汇总。
- 任务与结果也会暂存在当前浏览器 `localStorage` 中。

## Vercel 云端存储说明

推荐低成本方案：

1. 将本项目部署到 Vercel。
2. 在 Vercel 项目中添加 KV / Upstash Redis。
3. 确保环境变量中存在 `KV_REST_API_URL` 和 `KV_REST_API_TOKEN`。
4. 以后老师每次创建任务只会写入一条任务数据，学生链接形如 `https://your-site.vercel.app/?task=task_xxxxxxxx#student`，无需重新部署。
